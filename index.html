    Painel do dono

    Quando o servidor de vídeo estiver pronto, é aqui que você liga a geração com IA. Enquanto estiver desligada, o site usa a animação feita no próprio navegador.

    Como o servidor precisa responder
    GET  /saude → 200
POST /jobs  → {"id":"abc"}
  recebe: foto (JPEG em base64), nome, oferta, preco, cta, descricao, instrucao, narracao (texto para a voz), voz, estilo, formato {largura, altura}
  o servidor chama a API de vídeo e a API de voz ao mesmo tempo, junta as duas (ffmpeg) e devolve UM mp4 com imagem e áudio
GET  /jobs/abc → {"status":"fila|rodando|pronto|erro", "progresso":0-100, "video_url":"https://….mp4"}

    Na versão real, este painel fica restrito ao dono e a chave da RunPod fica só no servidor.

    Demonstração: sua conta fica salva só neste navegador.
